## Ограничения для разработки

⚠️ **КРИТИЧНО — не нарушать:**

- **minSdk = 28** (Android 9.0) — НЕ использовать API выше 28 без проверки `Build.VERSION.SDK_INT`
- **Запрещённые API:**
  - `window.insetsController` — только с API 30+ (обязательно `if (SDK_INT >= R)`)
  - `InputStream.readNBytes()` — только с API 33+ (использовать `read()`)
  - `WindowInsets.Type.*` — только с API 30+
- **2 ГБ RAM** — обязательно сжимать изображения при загрузке (`inSampleSize`)
- **Максимум bitmap в памяти** — ~24 МБ (1920×1080×4 bytes × 3 буфера)
- **32 ГБ диск** — кэш ограничить 500 МБ макс

## Количество устройств

- **6 кофеен** × **4 телика** = **~24 дисплея**
- Кофейни: Ак-Мечеть, Франко, Пушкина, Евпатория, Саки, Бахчисарай
