## Телевизор в Recovery Mode

### Симптомы

Телевизор показывает экран восстановления (Recovery) вместо обычного интерфейса Android TV. Обычно виден робот Android и надпись «No command» или меню с пунктами recovery.

### Причина

Сбой системы, неудачное обновление прошивки или повреждение системного раздела.

### Решение

1. С помощью пульта (кнопки громкости) выберите пункт **«Wipe data / Factory data reset»**.
2. Подтвердите выбор кнопкой питания или OK.
3. Дождитесь завершения сброса (может занять 3–5 минут).
4. Выберите **«Reboot system now»**.
5. После перезагрузки пройдите первоначальную настройку Android TV.
6. Установите приложение Teliki Signage заново.

> ⚠️ **Внимание:** сброс к заводским настройкам удалит ВСЕ данные с телевизора, включая установленные приложения и кэш. Потребуется заново настроить Wi-Fi, установить приложение и ввести OAuth-токен.

## Приложение падает при запуске

### Симптомы

Приложение открывается на долю секунды и сразу закрывается, или показывает сообщение «Приложение остановлено».

### Причина

Несовместимая версия Android. Приложение требует **API 28+ (Android 9.0 Pie)** или выше.

### Диагностика

Проверьте версию Android на телевизоре:

1. Откройте **Настройки** → **Об устройстве** (или **Сведения об устройстве**).
2. Найдите строку **«Версия Android»**.
3. Если версия ниже **9.0** — приложение не будет работать на этом устройстве.

### Решение

- Если Android ≥ 9.0, но приложение всё равно падает — очистите данные приложения:
  - **Настройки** → **Приложения** → **Teliki Signage** → **Очистить данные**
  - Перезапустите приложение
- Если Android < 9.0 — необходимо заменить телевизор / ТВ-приставку на модель с Android 9.0+.
- Проверьте логи через `adb logcat` (см. раздел ниже) для точной диагностики ошибки.

## Контент не отображается

### Симптомы

Приложение запускается, но показывает чёрный экран, заставку по умолчанию, или надпись «Нет контента».

### Возможные причины и решения

#### 1. Нет интернета

- Проверьте подключение к Wi-Fi: **Настройки** → **Сеть и интернет**.
- Убедитесь, что роутер работает и раздаёт интернет.
- Попробуйте открыть браузер на телевизоре и зайти на любой сайт.

#### 2. Неправильная структура папок на Яндекс.Диске

Убедитесь, что структура папок соответствует формату:

```
Teliki/
└── {Название кофейни}/
    └── {Экран N}/
        ├── файл1.mp4
        ├── файл2.jpg
        └── schedule.json  (опционально)
```

Частые ошибки:
- ❌ Файлы лежат прямо в `Teliki/` без подпапок
- ❌ Опечатка в названии папки (регистр имеет значение!)
- ❌ В приложении выбрана не та кофейня или не тот экран

#### 3. Истёк или невалидный OAuth-токен

- Откройте настройки приложения и проверьте токен.
- Попробуйте получить новый токен на [oauth.yandex.ru](https://oauth.yandex.ru).
- Вставьте новый токен в настройках приложения.

#### 4. Пустая папка на Яндекс.Диске

- Откройте Яндекс.Диск в браузере и убедитесь, что в папке экрана есть файлы.

#### 5. Кэш повреждён

- Очистите данные приложения: **Настройки** → **Приложения** → **Teliki Signage** → **Очистить данные**.
- Приложение скачает контент заново.

## Артефакты при воспроизведении видео

### Симптомы

Видео воспроизводится, но с визуальными искажениями: квадраты (макроблоки), зависания, рассыпание картинки, зелёные полосы.

### Причина

Видеофайл закодирован в формате или профиле, который не поддерживается аппаратным декодером телевизора. Большинство бюджетных Android TV устройств поддерживают только **H.264 Baseline Profile**.

### Решение

Перекодируйте видео с помощью FFmpeg:

```bash
ffmpeg -i input.mp4 \
  -c:v libx264 \
  -profile:v baseline \
  -level 4.0 \
  -pix_fmt yuv420p \
  -vf "scale='min(1920,iw)':'min(1080,ih)':force_original_aspect_ratio=decrease" \
  -b:v 4M \
  -c:a aac \
  -b:a 128k \
  -movflags +faststart \
  output.mp4
```

**Параметры:**

| Параметр | Значение | Зачем |
|----------|----------|-------|
| `-profile:v baseline` | Baseline Profile | Максимальная совместимость с ТВ |
| `-level 4.0` | Level 4.0 | Поддержка до Full HD |
| `-pix_fmt yuv420p` | YUV 4:2:0 | Стандартный формат пикселей |
| `-vf scale=...` | Макс. 1920×1080 | Ограничение разрешения |
| `-b:v 4M` | Битрейт 4 Мбит/с | Баланс качество/размер |
| `-movflags +faststart` | Быстрый старт | Ускоренное начало воспроизведения |

### Рекомендации по подготовке видео

- **Кодек:** H.264 (AVC), Baseline Profile
- **Разрешение:** максимум 1920×1080 (Full HD)
- **Битрейт:** 2–6 Мбит/с
- **Частота кадров:** 25 или 30 fps
- **Аудио:** AAC, 128 кбит/с (или без аудио, если не нужен звук)
- **Контейнер:** MP4

## Как читать логи (adb logcat)

### Подготовка

1. Установите **ADB** (Android Debug Bridge) на компьютер:
   - macOS: `brew install android-platform-tools`
   - Windows: скачайте [Platform Tools](https://developer.android.com/studio/releases/platform-tools)
   - Linux: `sudo apt install adb`

2. Включите **режим разработчика** на телевизоре:
   - **Настройки** → **Об устройстве** → нажмите 7 раз на **«Номер сборки»**
   - Вернитесь в настройки → появится пункт **«Для разработчиков»**
   - Включите **«Отладка по USB»** (или **«Отладка по сети»** для ADB over Wi-Fi)

3. Подключите компьютер к телевизору:
   - **По USB:** подключите USB-кабель
   - **По сети:** `adb connect <IP-адрес-ТВ>:5555`

### Просмотр логов

Все логи приложения:

```bash
adb logcat | grep -i "teliki"
```

Только ошибки:

```bash
adb logcat *:E | grep -i "teliki"
```

Логи с временными метками:

```bash
adb logcat -v time | grep -i "teliki"
```

Сохранить логи в файл (для отправки разработчику):

```bash
adb logcat -d > teliki_logs.txt
```

### На что обращать внимание

| Тег лога | Что означает |
|----------|-------------|
| `YandexDiskClient` | Ошибки работы с API Яндекс.Диска |
| `CacheManager` | Проблемы со скачиванием или кэшированием файлов |
| `ScheduleManager` | Ошибки парсинга schedule.json |
| `PlayerActivity` | Ошибки воспроизведения контента |
| `ExoPlayer` | Ошибки медиаплеера (кодеки, форматы) |

### Типичные ошибки в логах

```
E/YandexDiskClient: HTTP 401 Unauthorized
```
→ Невалидный OAuth-токен. Нужно получить новый.

```
E/YandexDiskClient: HTTP 404 Not Found
```
→ Указанная папка не существует на Яндекс.Диске. Проверьте путь.

```
E/CacheManager: Insufficient storage space
```
→ Недостаточно места на устройстве. Очистите кэш других приложений или используйте устройство с большим объёмом памяти.

```
E/ExoPlayer: Decoder init failed
```
→ Видеокодек не поддерживается. Перекодируйте видео (см. раздел выше).

## Приложение зависает на заставке

### Симптомы

Приложение показывает логотип или индикатор загрузки и не переходит к воспроизведению контента.

### Возможные причины

1. **Медленный интернет** — скачивание больших файлов занимает много времени. Подождите 5–10 минут.
2. **Яндекс.Диск временно недоступен** — подождите и перезапустите приложение.
3. **Слишком большие файлы** — уменьшите размер видеофайлов (рекомендуется до 100 МБ на файл).

### Решение

1. Подождите 10 минут — возможно, идёт первоначальная загрузка.
2. Перезапустите приложение.
3. Проверьте интернет-соединение.
4. Если не помогает — очистите данные приложения и настройте заново.
